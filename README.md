# Poppy Productions

Poppy Productions is an award-winning independent film, television, and commercial production house website. Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, GSAP (ScrollTrigger), and Lenis Smooth Scroll.

## Features

- **Cinematic Dark Editorial Design:** `#0A0A0A` pitch-black background with signature Poppy Orange-Red (`#F2613F`) accents.
- **Lenis Smooth Scroll & GSAP ScrollTrigger:** Hardware-accelerated fluid inertia scrolling and parallax effects.
- **Full-Screen Curtain Navigation Menu:** Animated overlay navigation with dedicated links to Home, About, Team, Productions, and Contact.
- **Interactive Team Showcase & 50/50 Modal:** 3-column portrait grid with a floating magnetic cross cursor and click-anywhere dismissal.
- **Dynamic Productions Grid & SSG Project Detail Pages:** Pre-rendered project pages (`/productions/[id]`) with synopses, cast details, stills gallery, and video previews.
- **Full-Screen Hero Video & Showreel Lightbox:** Seamless background video playback and interactive showreel modal.
- **Instant Search Modal & Newsletter API:** Interactive search and newsletter subscription.

## Tech Stack

- **Framework:** Next.js 14 (App Router, React 18, TypeScript)
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** GSAP 3 (ScrollTrigger), Lenis Smooth Scroll, Framer Motion, Lucide Icons
- **Deployment:** Vercel

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```
